## 🏬 ShopNest Retail Sales Analysis

### 📌 Project Overview

This project analyzes ShopNest’s retail transaction data to **identify sales performance drivers, customer purchasing trends, and product category growth**. The aim was to generate insights that could support **inventory optimization, targeted promotions, and customer retention strategies**.

---

### 🔎 Key Insights

-  📈 **Sales Growth:** Electronics and Apparel emerged as the **fastest-growing categories**, contributing the largest share to YoY revenue growth.

-  👥 **Customer Segmentation:** Repeat customers generated **\~45% higher lifetime value** compared to one-time shoppers, emphasizing the need for loyalty programs.

-  📍 **Regional Insights:** Metro stores delivered **higher transaction volumes**, while suburban outlets showed **higher average order values**, highlighting diverse customer behaviors.

-  ⏱️ **Seasonality:** Festive and holiday seasons boosted sales by **\~30% above average months**, showing strong seasonal dependency.

-  💳 **Basket Analysis:** Cross-selling opportunities were identified between **Electronics + Accessories** and **Groceries + Personal Care** categories.
